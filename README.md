# Сайт «Belarus»

Школьный сайт про Беларусь на английском языке — для проекта по английскому.
Три страницы: главная, страница-квиз с 6 вопросами и Privacy Policy.

## GitHub Pages

Онлайн-версия: https://timgihangir-rgb.github.io/Web-site-about-a-belarus/

## Как открыть локально

Дважды кликните на `index.html` — и всё. Картинки сохранены локально,
интернет не нужен.

## Файлы

```
├── index.html   — главная: факты (карточки), природа, знаменитые места, еда
├── quiz.html    — квиз: 6 картинок, под каждой 4 варианта ответа
├── privacy.html — страница Privacy Policy (ссылка в футере)
├── css/
│   └── style.css — простые светлые стили на белом фоне
├── js/
│   └── quiz.js  — проверка ответов, счёт, «Try again»
└── images/      — 11 фотографий (Wikimedia Commons)
```

## Квиз

6 вопросов с картинками — по 4 варианта ответа на каждый:

1. Мирский замок
2. Зубр из Беловежской пущи
3. Национальная библиотека
4. Драники
5. Несвижский замок
6. Красный костёл в Минске

Кнопки: **Check answers** (проверка и счёт) и **Try again** (сброс).
Правильные ответы подсвечиваются зелёным, неверные — красным.
Правильные варианты разбросаны по A/B/C/D.
